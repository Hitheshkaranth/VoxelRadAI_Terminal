# DICOM regression fixtures

`CT_small.dcm` and `MR_small.dcm` are unchanged pydicom test files, pinned to release v3.0.1:

- https://raw.githubusercontent.com/pydicom/pydicom/v3.0.1/src/pydicom/data/test_files/CT_small.dcm
- https://raw.githubusercontent.com/pydicom/pydicom/v3.0.1/src/pydicom/data/test_files/MR_small.dcm

The upstream MIT license is included as `PYDICOM-LICENSE.txt`. These small fixtures exercise real DICOM header/pixel decoding and source-modality preservation. They are software test inputs, not clinical validation data.
