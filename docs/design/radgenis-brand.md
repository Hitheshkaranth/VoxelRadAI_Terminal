# RadGenis identity

Product name: **RadGenis** (formerly VoxelRad AI). Public domain: **radgenis.com**; voxelradai.com and www.radgenis.com redirect to it with a 308. Wordmark: RadGenis, set in one word. The app keeps the original VoxelRad peacock-and-medical-spear mark (`app/public/skanda-mark.png`) throughout, including the browser favicon, Apple touch icon, share image and pitch deck.

Keep the existing image-first workspace, Figtree typography, accessible light/dark surfaces and CT login cine. Product identity appears in navigation, page titles, empty state, account screens, report exports and documentation. The longer navigation name stays on one line beside its 24px mark.

Skanda remains the supported model's technical name. Model identifiers, `voxelrad.*` storage keys, `X-VoxelRad-*` API headers, metrics names, prompts, API extension keys, IndexedDB identifiers, session cookie names, historical releases and evaluation records are intentionally preserved. This prevents rebranding from silently disconnecting existing models or studies. Old default institution labels (Skanda Radiology, VoxelRad AI, RadGenie) migrate to RadGenis; custom institution names remain unchanged.

The Vercel launch is authenticated-only. The root Vercel build enables server authentication and deploys the API alongside the frontend. The repository name remains unchanged to preserve links and release history.
