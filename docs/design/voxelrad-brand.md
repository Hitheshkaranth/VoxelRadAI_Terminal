# VoxelRad AI identity

Product name: **VoxelRad AI**. Public domain: **voxelradai.com**. Wordmark: voxelrad with a separate AI suffix. The app uses the original Skanda peacock-and-medical-spear mark throughout, including the browser favicon and Apple touch icon. The product name remains VoxelRad AI.

Keep the existing image-first workspace, Figtree typography, accessible light/dark surfaces and CT login cine. Product identity appears in navigation, page titles, empty state, account screens, report exports and documentation. The longer navigation name stays on one line beside its 24px mark.

Skanda remains the supported model's technical name. Model identifiers, prompts, API extension keys, IndexedDB identifiers, session cookie names, historical releases and evaluation records are intentionally preserved. This prevents rebranding from silently disconnecting existing models or studies. The old default institution label migrates to VoxelRad AI; custom institution names remain unchanged.

The Vercel launch is authenticated-only. The root Vercel build enables server authentication and deploys the API alongside the frontend. The repository name remains unchanged to preserve links and release history.
