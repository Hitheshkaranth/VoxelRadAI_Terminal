# Skanda Radiology v0.2.0-beta.1

This beta expands the scan workspace and adds a private-installation server foundation.

## Changes

- Larger CT/MRI and X-ray workspaces with integrated scan controls and collapsible panels.
- Official editable shadcn buttons, popovers and tooltips; neutral dashboard styling and responsive layouts.
- Display adjustments, theme controls and loading feedback.
- Optional authenticated server mode with PostgreSQL sessions, administrator tools, saved image studies and expiring/revocable share links.
- Docker Compose deployment, migration and backup guidance, and expanded automated tests.

## Packages

- `skanda-radiology-v0.2.0-beta.1-source.zip`: tagged source, Dockerfiles and Compose configuration. Extract, copy `config.example` to `.env`, configure credentials, then follow `docs/deployment.md`.
- `skanda-radiology-v0.2.0-beta.1-web.zip`: prebuilt local-only frontend. Serve the extracted directory with an HTTP server; do not open `index.html` directly. This bundle does not include the API, database, model service, or model weights. Use the source package and Compose for authenticated server mode and model proxy routing.
- `SHA256SUMS.txt`: SHA-256 checksums for both ZIP files.

## Validation and beta limits

Application and server automated tests and the frontend production build pass. Browser inspection covered CT/MRI single-plane, MRI three-plane, display popovers and responsive CT controls. Earlier synthetic integration covered authenticated study/session/sharing workflows.

X-ray visual import verification, comprehensive accessibility/device testing and live inference verification remain outstanding. The development model service was offline. This release does not establish clinical validation or production-scale readiness. Model weights, credentials, patient data, dependency folders and local environment files are excluded from the packages.

See `docs/validation/2026-11-10-scan-workspace.md`, `docs/validation/2026-11-10-platform-qc.md` and `docs/deployment.md` for details.
